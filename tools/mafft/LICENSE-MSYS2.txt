Minimal MSYS2 runtime bundled with the MAFFT 7.505 Windows x64 package
=====================================================================

The runtime under `usr/bin/` is a subset of the MSYS2 environment that the
MAFFT project ships inside its official Windows binary bundle. CYAN does not
modify these files. They are included only because `mafft.bat` invokes
`usr/bin/bash` to run the `usr/bin/mafft` shell script.
